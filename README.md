# DSMS-Releases

Fertige Releases von DSMS: Programmdateien, Pakete, Abbild-Datei für die Synology, `SHA256SUMS` und Hinweise. Hier liegt kein Quellcode.

Die Seite *Updates* in der DSMS-Konsole liest diese Liste, zeigt neue Versionen mit ihren Änderungen und Upgrade-Hinweisen an und holt das Update auf Knopfdruck.

Gefüllt wird das Repo von `tools/build/release-public.sh` beim Release.
